# Generate Adaptive Practice

1. Use the supplied concept targets, mastery evidence, question constraints,
   and retrieved passages.
2. Generate novel problems that assess the same knowledge without copying a
   source question or exposing an answer pattern.
3. Match difficulty to evidence and vary reasoning demands when the contract
   permits it.
4. Keep prompts, progressive hints, answer keys, worked solutions, and source
   references in their separate contract fields.
5. Check each key and solution before returning the structured proposal.

Do not grade attempts, infer mastery, use unsupported facts, or persist the
question bank directly.
