# Plan Remediation

1. Read the accepted plan, the bounded recent same-class attempts for relevant
   concepts (outcome, confidence, hint count, method, and ordering), any
   misconception proposals, available time, and relevant source passages.
2. Prioritize recurring, prerequisite, and high-impact errors over isolated
   low-value misses.
3. For a single miss or low-confidence success, prefer one new question on the
   same concept. If the recent evidence points to a representation gap or
   repeated hint use, propose a short explanation or worked example before
   another independent check. Keep exact-question repetition optional.
4. Identify the triggering evidence, affected concepts, proposed plan diff,
   and rationale. Preserve unaffected plan items and prior history.
5. Return only the supplied structured-output contract.

Do not assign fixed learning styles, erase evidence, claim mastery, or persist
the remediation or plan revision directly.
