# Build Training Plan

1. Use the accepted course map as the structural boundary; do not reinterpret
   raw sources unless passages are explicitly supplied.
2. Schedule toward stated deadlines and available time while respecting
   prerequisites, retrieval spacing, and current evidence.
3. Prefer the smallest plan change that addresses new quiz or retention
   evidence. Preserve unaffected work.
4. Identify the evidence and rationale for every changed priority or activity.
5. Return only the supplied structured-output contract.

Do not use fixed learning-style labels, erase prior plan history, mark mastery
without evidence, or persist changes directly.
