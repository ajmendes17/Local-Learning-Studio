# Changelog

Major user-facing changes are recorded here so collaborators can see what
changed without comparing every commit. Entries are grouped under **Unreleased**
while work is being reviewed, then moved to a dated release heading when
published.

## Unreleased

### Added

- Added assessment reconciliation to compare course assessment records and
  generated Obsidian notes against exam reviews and scheduled course coverage.
- Added accept/keep-separate controls for duplicate generated Obsidian
  assessment notes. Accepted merges retain one note, preserve personal note
  text, and archive duplicate snapshots in the vault.
